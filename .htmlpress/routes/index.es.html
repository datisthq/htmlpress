Escribe en Markdown o HTML sencillo, y htmlpress añade layout, tema, navegación y recarga en vivo, construidos con web components y CSS, todo escapable. Ideal para documentación interna y para publicar contenido.

Empezar Ver el código
  • curl -fsSL https://htmlpress.dev/install.sh | sh
  • pip install htmlpress
  • npm install gethtmlpress
  • cargo install htmlpress

No te estorba

Sin framework, sin configuración de compilación, sin estructura obligatoria. Una carpeta de Markdown o HTML ya es un proyecto.

  • Cualquier estructura de archivos

    Una página es cualquier archivo .md o .html: Markdown con frontmatter, o HTML desde un simple fragmento hasta un documento completo. Déjalas planas o anídalas: una carpeta con index.html se convierte en un grupo de navegación, y cualquier otro archivo se copia tal cual.

  • Web components, light DOM

    Cada componente es un elemento personalizado estándar: sin framework, sin shadow DOM. Tu CSS y los tokens del tema llegan dentro, y el texto queda en la página para la búsqueda y los agentes. Un archivo en .htmlpress/components/ añade tu propia etiqueta.

  • Escapa lo que quieras

    Reemplaza el layout, el tema o cualquier componente integrado desde .htmlpress/, o dibuja una página propia como ruta personalizada. Esta landing page es una de ellas. 

.htmlpress/
├─ routes/
│  └─ index.html      ← this page, drawn bare
└─ components/
   └─ site-hero.css   ← your own component
guides/
├─ setup.html
└─ faq.html
images/               ← copied as they are
htmlpress.yaml

Preciosa por defecto

Un tema cuidado, los componentes que necesita una documentación y valores predeterminados sensatos. Personaliza solo lo que quieras.

Los encabezados, las listas, las tablas, el código, <details>, <figure> y <kbd> se ven bien sin ninguna clase.

Avisos, pestañas, pasos, tarjetas, árboles de archivos, insignias, iconos, tablas ordenables, diagramas Mermaid e imágenes ampliables, como elementos personalizados en light DOM.

Resaltado al construir en más de 220 lenguajes, con títulos, pestañas, diff, foco y marcas de línea, en un tema claro y otro oscuro.

Agrupada por carpeta, ordenada por <meta name="order">, con una tabla de contenidos y enlaces de anterior y siguiente.

Un índice de texto completo escrito al construir y abierto con S; la página que abre un resultado resalta la coincidencia.

Divide un sitio en secciones con su propia pestaña y barra lateral: entradas fechadas con un feed RSS, o una página por versión desde un CHANGELOG.md.

La navegación se convierte en un panel lateral, los selectores en hojas inferiores y nada se desplaza en horizontal.

Un tema oscuro según el sistema o el interruptor, y cada color, fuente y ancho es un token --htmlpress-*.

Traduce una página junto a su original como page.es.html: cada idioma tiene su prefijo, navegación, búsqueda y textos de interfaz.

Pensado para agentes de programación

Los agentes conocen Markdown y HTML mejor que cualquier lenguaje de plantillas. Htmlpress mantiene pequeño su trabajo y cada respuesta legible por máquinas. 

$ htmlpress build docs --json
{
  "output": "docs/.htmlpress/build",
  "pages": 8,
  "files": 12
}

$ htmlpress build --json '{"root":"docs","out":"dist"}'

$ htmlpress --llms

  • Entra Markdown o HTML sencillo

    Sin framework, sin sintaxis que aprender, sin clases utilitarias: cuantas menos opciones ofrece una página, más se parecen las páginas a un mismo sitio.

  • Todos los comandos hablan JSON

    --json imprime el resultado en stdout y recibe la entrada como JSON; los registros y los errores van a stderr.

  • La CLI de una sola lectura

    htmlpress --llms lista el esquema de entrada y salida de cada comando como herramientas con forma de MCP.

  • Una copia en Markdown de cada página

    Cada página obtiene un index.md junto a su HTML, enlazado desde el head, para que un agente lea el contenido sin el marcado.

  • llms.txt de serie

    Un índice llms.txt de cada copia, agrupado como la navegación y anunciado en una cabecera Link de la página de inicio.

  • Una skill para tu agente

    Cinco skills enseñan a Claude Code, Cursor o Codex a escribir, configurar, rediseñar y desplegar un sitio.
