Htmlpress

Htmlpress turns a folder of HTML pages into a site. Each page keeps its own markup, and htmlpress adds one layout, one theme, a navigation and a live-reloading dev server.

It is made for coding agents. They write plain semantic HTML, which they know better than any templating language, and every page comes out looking like the same site: no framework, no build config, no utility classes.

Plain HTML in

A page is any .html file, a full document or a bare fragment.

A site out

One layout, a navigation and a theme styled from the HTML elements themselves.

One binary

A single Rust binary, installed from npm, PyPI or crates.io.

Quick start

npx gethtmlpress start docs

That serves docs/ on http://127.0.0.1:8080 and rebuilds on every save. When it looks right, build it: 

npx gethtmlpress build docs

The site lands in docs/.htmlpress/build, ready for any static host. This site is built that way from the docs/ folder of the repository.

Htmlpress is in technical preview: the page contract may still change before 1.0.
