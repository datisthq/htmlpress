Components

The theme styles HTML elements directly: headings, paragraphs, lists, tables, code, <details>, <figure>, <kbd>. Write semantic HTML and it already looks right. A few hp-* elements cover what HTML has no element for. They are light-DOM custom elements, so their content stays plain HTML that reads well even before the script loads.

Callout

A note. type is info (the default), success, warning or danger.

Never edit .htmlpress/build: every build replaces it.

 
<hp-callout type="warning"><p>Mind the gap.</p></hp-callout>

Grid and card

One

Cards fill the grid's columns.

Two

Columns wrap on narrow screens.

 
<hp-grid>
  <hp-card><h3>One</h3><p>…</p></hp-card>
  <hp-card><h3>Two</h3><p>…</p></hp-card>
</hp-grid>

Tabs

Each <section> is a tab, named by its title.

Without the script, the sections simply stack.

 
<hp-tabs>
  <section title="npm">…</section>
  <section title="PyPI">…</section>
</hp-tabs>

Theme tokens

Colors, fonts and widths are CSS custom properties on :root, with a dark set under prefers-color-scheme. Override them from a page's own stylesheet: 

:root {
  --hp-accent: oklch(0.6 0.18 30);
  --hp-font: "Inter", system-ui, sans-serif;
  --hp-width: 52rem;
}

Layout escape

A .htmlpress/layout.html in the project replaces the built-in layout. It is a minijinja template that gets site, page, nav, description, assets and reload; start from the built-in one.
