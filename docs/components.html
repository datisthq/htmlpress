Components

The theme styles HTML elements directly: headings, paragraphs, lists, tables, code, <details>, <figure>, <kbd>. Write semantic HTML and it already looks right. A few htmlpress-* elements cover what HTML has no element for. They are light-DOM custom elements, so their content stays plain HTML that reads well even before the script loads.

Callout

A note. type is info (the default), success, warning or danger.

Every page built.

label replaces the heading the type gives.

Never edit .htmlpress/build: every build replaces it. 

<htmlpress-callout type="warning" label="Mind the gap"><p>…</p></htmlpress-callout>

Grid and card

Cards fill responsive columns; cols fixes their number from 2 to 4. A link in a card's heading makes the whole card clickable.

Tabs

Each <section> is a tab, named by its title. Tabs that share a sync key switch together and remember the choice.

pip install htmlpress

A prebuilt binary per platform.

A binary wheel.

Theme tokens

Colors, fonts and widths are CSS custom properties on :root, with a dark set under prefers-color-scheme or the header's theme toggle. Override them from a page's own stylesheet: 

:root {
  --htmlpress-accent: oklch(0.6 0.18 30);
  --htmlpress-font: "Inter", system-ui, sans-serif;
  --htmlpress-width: 52rem;
}

Layout

The layout is plain HTML. Htmlpress fills its <head> (charset, viewport, title, description, canonical link, the theme, the styles and scripts of the components the page uses, then the page's own head tags) and replaces these elements at build time:

<htmlpress-content>
The page's content.
<htmlpress-brand>
The site title, linking home.
<htmlpress-nav>
Every page, grouped by top folder; a folder's group is named by its index page.
<htmlpress-links>
The links from htmlpress.toml.
<htmlpress-toc>
The page's <h2> and <h3>, highlighting the one in view. A heading without an id gets one from its text.
<htmlpress-pager>
The previous and next pages in navigation order.
<htmlpress-edit>
An "Edit this page" link from edit in htmlpress.toml.

An element with nothing to show is removed. <htmlpress-nav-toggle>, <htmlpress-theme-toggle> and <htmlpress-back-to-top> are built by the script in the browser. A .htmlpress/layout.html in the project replaces the built-in layout, and every component's styles and script can be replaced or added the same way: see Escaping.
