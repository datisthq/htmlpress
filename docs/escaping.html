Escaping

Every built-in file can be replaced: drop a file at the same path under .htmlpress/ and the build uses it instead. Delete it and the default is back. The dev server picks up either change at once.

  • .htmlpress
    • layout.html
    • styles
      • tokens.css
      • layout.css
      • content.css
    • scripts
      • code.js
    • components
      • htmlpress-callout.css
      • htmlpress-tabs.css
      • htmlpress-tabs.js
      • site-footer.html

The escape command

htmlpress escape copies a default into .htmlpress/ to start from. Name a file by its path, or a component by its tag for all of its files: 

$ htmlpress escape                       # list every file, marking the escaped ones
$ htmlpress escape htmlpress-tabs        # its .css and .js
$ htmlpress escape layout.html styles/tokens.css

It never overwrites a file you already have: delete it first to start over. An escaped copy keeps the code it was copied from, so after an upgrade it misses the new defaults.

What each file is

layout.html
The page around the content, plain HTML with the layout elements htmlpress fills.
styles/*.css
The global theme, joined into one theme.css on every page: tokens.css (the --htmlpress-* values), layout.css (the chrome around the page) and content.css (headings, prose, tables, code).
scripts/code.js
The copy button on code blocks and the link on each heading.
components/<tag>.css and .js
One component each. Its styles sit in @scope (<tag>), so they never reach outside it, and its script defines only that element. A page links only the components it uses.

Your own components

A file under components/ with a new tag adds a component. Its .html replaces every <tag> in the layout and the pages at build time; its .css and .js load wherever the tag appears. 

<!-- .htmlpress/components/site-footer.html -->
<footer><p>Built by my team · 2026</p></footer>

/* .htmlpress/components/site-footer.css */
@scope (site-footer) {
  footer { color: var(--htmlpress-muted); }
}

Then put <site-footer></site-footer> in an escaped layout.html or any page. A tag needs a hyphen and lowercase letters, as every custom element does. A component's .html may hold other components, but not another project component's tag: it is pasted in once, never rewritten again.

The htmlpress- prefix is reserved. A file named for a tag htmlpress does not ship, such as htmlpress-calout.css, fails the build, and so does any file under styles/ or scripts/ that replaces nothing.

What stays fixed

The markup inside <htmlpress-nav>, <htmlpress-toc>, <htmlpress-pager> and the other layout elements is built from the site, so only their .css and .js can be escaped. A components/htmlpress-brand.html replaces one with your own static HTML.
