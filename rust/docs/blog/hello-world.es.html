¿Qué es Htmlpress?

Htmlpress convierte una carpeta de páginas HTML en un sitio, pensado para agentes de programación. Ofrece:

  • Un layout y un tema, reemplazables archivo por archivo
  • Resaltado de código en tiempo de compilación
  • Componentes e iconos integrados
  • Un servidor de desarrollo con recarga en vivo
