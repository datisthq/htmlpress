静态站点生成器，
专为
纯 HTML 而生。

编写语义化 HTML 页面，或者让你的智能体来写。Htmlpress 添加布局、主题、导航和实时重载的开发服务器，每个部分都可弹出。适合实时内部文档，也适合对外发布。

快速开始 查看源码
  • curl -fsSL https://htmlpress.dev/install.sh | sh
  • pip install htmlpress
  • npm install gethtmlpress
  • cargo install htmlpress

绝不碍事

没有框架，没有构建配置，没有强制的目录结构。一个装满 HTML 的文件夹本身就是一个项目。

  • 任意 HTML 文件夹

    页面就是任意 .html 文件，可以是完整文档，也可以是一个裸片段。文件夹会成为导航分组，其他所有文件则原样复制。

  • 你自己的组件

    .htmlpress/components/ 中的文件定义一个新标签：它的 HTML 会被嵌入页面，它的 CSS 和 JS 只在使用它的页面上加载。

  • 一切皆可弹出

    在 .htmlpress/ 中替换布局、主题或任意内置组件，或者为某个页面提供独立的布局。这个落地页就是如此。 

.htmlpress/
├─ layouts/
│  └─ landing.html    ← this page's chrome
└─ components/
   └─ site-hero.css   ← your own component
guides/
├─ setup.html
└─ faq.html
images/               ← copied as they are
index.html            ← a page too
htmlpress.yaml

默认即精美

精致的主题、文档所需的组件以及合理的默认设置。只需自定义你想改的部分。

基于元素的样式

标题、列表、表格、代码、<details>、<figure> 和 <kbd> 无需任何类名即可正确呈现。

弥补 HTML 空缺的组件

提示框、标签页、步骤、卡片、文件树、徽章、图标、可排序表格、Mermaid 图表和可缩放图片，全部以 light DOM 自定义元素的形式提供。

代码高亮

构建时高亮 220 多种语言，支持标题、标签页、差异、聚焦和行标记，并提供浅色和深色主题。

源自文件夹的导航

按文件夹分组，按 <meta name="order"> 排序，并带有目录以及上一页和下一页链接。

内置搜索

构建时生成全文索引，按 S 打开；结果所打开的页面会高亮匹配内容。

文档、博客和更新日志

将站点拆分为多个分区，各有自己的标签页和侧边栏：带 RSS 订阅的日期文章，或从 CHANGELOG.md 生成的每版本一页。

手机上同样自如

导航变为抽屉，选择器变为底部面板，没有任何内容会横向滚动。

深色模式和主题令牌

深色主题可跟随系统或通过开关切换，每种颜色、字体和宽度都是一个 --htmlpress-* 令牌。

多语言

在原页面旁以 page.es.html 翻译：每种语言都有自己的前缀、导航、搜索和界面文案。

实时重载

htmlpress start 在每次保存时重新构建并刷新浏览器，弹出文件和组件也不例外。

静态输出

htmlpress build 将纯文件写入 .htmlpress/build，带有规范链接，可部署到任何静态托管平台。

一个二进制文件，三个渠道

单个 Rust 可执行文件，可通过 npm、PyPI 或 crates.io 安装。无需安装其他任何东西。

为编码智能体打造

智能体对 HTML 的了解远胜于任何模板语言。Htmlpress 让它们的工作保持简单，并让每个输出都可被机器读取。 

$ htmlpress build docs --json
{
  "output": "docs/.htmlpress/build",
  "pages": 8,
  "files": 12
}

$ htmlpress build --json '{"root":"docs","out":"dist"}'

$ htmlpress --llms

  • 输入纯语义化 HTML

    没有框架，没有需要学习的语法，没有工具类：页面提供的选择越少，所有页面看起来就越像同一个站点。

  • 每条命令都支持 JSON

    --json 将结果输出到 stdout，并以 JSON 格式接收输入；日志和错误输出到 stderr。

  • 一次读懂 CLI

    htmlpress --llms 以 MCP 风格的工具列出每条命令的输入和输出模式。

  • 每个页面的 Markdown 副本

    每个页面旁都有一份 index.md，并在页面 head 中链接，智能体无需解析标记即可读取内容。

  • 开箱即用的 llms.txt

    一个列出所有副本的 llms.txt 索引，按导航分组，并通过首页的 Link 头公布。

  • 为你的智能体准备的技能

    五个技能教会 Claude Code、Cursor 或 Codex 编写、配置、重塑样式并部署站点。
