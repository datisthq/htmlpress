语法主题

带有 language-* 类的代码块会在构建时由 giallo 进行高亮，它运行 VS Code 的 TextMate 语法和主题，输出与 Shiki 相同。每个词法单元都通过 CSS 的 light-dark() 同时携带两个主题的颜色，因此主题切换按钮也会切换代码颜色，无需脚本，也不会闪烁。

配置

默认值与 Livemark 相同：

codeThemeLight: catppuccin-latte
codeThemeDark: catppuccin-mocha

约 60 个内置主题中的任何一个都可以使用；可在 Shiki playground 中查看。未知的名称会导致构建失败。代码块的边框、背景和字体仍来自 styles/content.css。

常用搭配

  • catppuccin-latte / catppuccin-mocha（默认）
  • github-light / github-dark
  • one-light / one-dark-pro
  • solarized-light / solarized-dark
  • rose-pine-dawn / rose-pine
  • vitesse-light / vitesse-dark

关于无障碍

无论给代码设置什么颜色，发布前都请用对比度工具逐一检查它们与代码块背景的对比度。常规尺寸文字所需的阈值为 4.5:1（WCAG AA）。

另请参阅

  • Code Blocks：编写方面的说明。
  • 覆盖/弹出：替换主题的代码样式或复制按钮脚本。
