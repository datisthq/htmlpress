Customization

Htmlpress exposes a handful of hooks for tailoring how your site looks, what it contains, and how files flow through the build. Each area has its own page.

htmlpress.yaml basics: include/exclude globs for your content.

Add external links to the header or the sidebar.

Article Patches

Override a page's metadata from config, without editing the file.

Overriding/Escaping

Replace any built-in layout, stylesheet, script or component via .htmlpress/.

Custom Routes
