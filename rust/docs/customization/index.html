Customization

Htmlpress exposes a handful of hooks for tailoring how your site looks, what it contains, and how files flow through the build. Each area has its own page.

Topics

Configuration

htmlpress.yaml basics: include/exclude globs for your content.

Site title, description, canonical URL, logo, and favicon.

Article Sections

Group a folder's pages in the sidebar under its index page.

Article Patches

Override a page's metadata from config, without editing the file.

External Links

Add external links to the header or the sidebar.

Syntax Themes

Light and dark themes for code blocks.

Custom Routes

Give a page its own chrome with a layout in .htmlpress/layouts/.

Translations

Publish the site in several languages, with a picker and fallbacks.

Versioning

Docs for several releases, with a section or a deploy per version.

Overriding/Escaping

Replace any built-in layout, stylesheet, script or component via .htmlpress/.
