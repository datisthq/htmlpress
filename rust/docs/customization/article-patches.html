Article Patches

A patches key in htmlpress.yaml will set a page's title, order or description from config, for an HTML file that is also read elsewhere and should stay free of htmlpress-only metas. Today a page's metadata lives only in its own <head>.

Sometimes a file doubles as both site content and a file that's read elsewhere, a shared page in another project. Adding htmlpress-only <meta> tags to it pollutes the other view.

Basic usage

Each patch will name a file by its path and the metadata to apply, as if the matching <title> and <meta> tags were in its head.

Fields

A patch will take a file, the project-relative path, and the page fields to set: those a page's head sets today, such as the title, description, order and layout.

Merge semantics

A patch's fields will apply on top of the page's own head; anything a patch leaves out keeps its normal value.

What you can't patch

The content: the body of a page is always the body of the file.
