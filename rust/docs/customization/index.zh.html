自定义

Htmlpress 提供了少量钩子，用于调整站点的外观、内容，以及文件在构建中的流转方式。每个方面都有单独的页面介绍。

主题

配置

htmlpress.yaml 基础：用于筛选内容的 include/exclude glob 模式。

站点元数据

站点标题、描述、规范 URL、Logo 和 favicon。

文章分区

在侧边栏中把一个文件夹的页面归到它的索引页之下。

文章补丁

通过配置覆盖页面的元数据，无需编辑文件本身。

外部链接

在页眉或侧边栏中添加外部链接。

语法主题

代码块的浅色与深色主题。

自定义路由

使用 .htmlpress/layouts/ 中的布局，为页面提供独立的外观框架。

翻译

以多种语言发布站点，带有语言选择器和回退机制。

版本管理

为多个发布版本提供文档，每个版本一个分区或一次部署。

覆盖/弹出

通过 .htmlpress/ 替换任何内置的布局、样式表、脚本或组件。

AI 智能体

面向 AI 智能体的 Markdown 副本、llms.txt、内容信号和智能体技能。
