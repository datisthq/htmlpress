Agentes de IA

Cada compilación publica tu sitio en los formatos que mejor leen los agentes de IA, junto al HTML que reciben los navegadores. No necesitas configurar nada para ello. Las dos claves de abajo solo lo ajustan.

Qué genera la compilación

Archivo Propósito
<page>.md Una copia en Markdown de cada página junto a su HTML: guides/build.html obtiene guides/build.md, con su título, descripción y contenido, y cada componente reducido a Markdown simple (un callout a una cita, las pestañas a encabezados en negrita)
/llms.txt Un índice llms.txt: el título y la descripción del sitio y, después, la copia en Markdown de cada página con su descripción, agrupadas como las agrupa la navegación
/index.md La copia de la página de inicio, o una copia de llms.txt cuando el proyecto no tiene index.html
/robots.txt Una línea Content-Signal que indica cómo pueden usar tu contenido los sistemas automatizados
/_headers Para Cloudflare y Netlify: una cabecera Link en la página de inicio que apunta a llms.txt, index.md y al índice de skills
/.well-known/agent-skills/index.json Un índice de descubrimiento de Agent Skills, cuando se define skills

Cada página lleva además <link rel="alternate" type="text/markdown"> apuntando a su copia, y la barra de herramientas de la página enlaza la copia y, con su script, la copia al portapapeles o abre la página en ChatGPT o Claude.

Un archivo del proyecto con el mismo nombre reemplaza al generado. _headers es la única excepción: tus reglas se conservan y la regla Link generada se añade después de ellas. htmlpress start ejecuta la misma compilación, así que también sirve estos archivos.

Señales de contenido

contentSignals controla la línea de Content Signals en robots.txt. Las tres señales valen true por defecto: 

contentSignals:
  search: true # build a search index and show links to your pages
  aiInput: true # feed pages to a model answering a question in real time
  aiTrain: false # train or fine-tune models on your content

La línea que produce queda en el grupo User-agent: *: Content-Signal: search=yes, ai-input=yes, ai-train=no.

Skills de agente

Si tu proyecto incluye Agent Skills, apunta skills a sus archivos SKILL.md, con un glob o una lista, relativos al proyecto: 

skills: .skills/*/SKILL.md

Cada skill encontrada se publica en /.well-known/agent-skills/<name>/SKILL.md y se lista en index.json con un resumen sha256. Su frontmatter necesita un name (letras minúsculas, dígitos y guiones simples, como máximo 64 caracteres) y una description (como máximo 1024), y la compilación falla si falta alguno o si dos skills comparten nombre. Este sitio publica la skill propia de htmlpress en /.well-known/agent-skills/.

Markdown bajo petición

Los agentes piden Markdown enviando Accept: text/markdown a la URL de la página. Un hosting estático no puede responder a eso por sí solo, pero una reescritura en tu CDN puede servir la copia .md de la página para esas peticiones y dejar el HTML para todos los demás. Cada página tiene una copia, así que la reescritura nunca apunta a un archivo inexistente. Para una regla lista para usar, consulta Cloudflare.
