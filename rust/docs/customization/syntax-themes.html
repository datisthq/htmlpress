Syntax Themes

Htmlpress does not highlight code yet. Syntax highlighting will color <pre><code> blocks at build time, with a light and a dark theme that follow the visitor's theme.

Today a code block is styled by the theme alone: styles/content.css sets its font, background and border from the --htmlpress-* tokens, in light and dark, and scripts/code.js adds a copy button.

Configuration

Light and dark theme keys in htmlpress.yaml will pick the themes. Until then, restyle code blocks by escaping styles/content.css or overriding the tokens it reads in styles/tokens.css.

A note on accessibility

Whatever colors you give code, check each one against the code block's background with a contrast tool before shipping. The threshold you need for normal-size text is 4.5:1 (WCAG AA).
