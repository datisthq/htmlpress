媒体

图片就是普通的 <img> 元素，会缩放到内容宽度。用 <figure> 包裹并加上 <figcaption> 即可添加图注。

内部图片

引用项目中的图片；所有非页面文件都会复制到输出中的相同路径：

<img src="/screenshots/docs.webp" alt="An htmlpress docs page">

相对的 src、srcset 或 poster 从页面的源文件解析，因此无论是在页面的文件夹 URL、语言前缀之下，还是另一个 <meta name="path"> 处，它都仍然有效。

主题图片

在 <img> 上设置 data-theme="light" 或 data-theme="dark"，图片就只在对应主题下显示，既跟随页眉的主题切换，也跟随系统设置；Livemark 风格的 src 结尾 #light 和 #dark 同样有效。把两张图片并排放置： 

<img src="/screenshots/docs.webp" alt="The docs" data-theme="light">
<img src="/screenshots/docs-dark.webp" alt="The docs" data-theme="dark">

图片缩放

<htmlpress-zoom> 内的图片点击后会全屏打开；点击任意位置即可关闭。内部图片、外部图片和 base64 图片都适用。 

<htmlpress-zoom><img src="screenshot.png" alt="The docs site"></htmlpress-zoom>

视频块

<htmlpress-youtube> 内的链接会变成该视频的播放器（支持 watch、youtu.be、embed、shorts 或 live URL）；没有脚本时它仍是一个链接： 

<htmlpress-youtube>
  <a href="https://www.youtube.com/watch?v=dQw4w9WgXcQ">The video</a>
</htmlpress-youtube>
