Redacción

Htmlpress acepta HTML semántico simple desde el primer momento, más un pequeño conjunto de componentes htmlpress-* para lo que HTML no tiene elemento: avisos, pestañas, pasos, tarjetas, terminales, diagramas y más. Un proyecto es una carpeta: cada archivo .html que contiene es una página, y cualquier otro archivo se copia tal cual a la salida, en la misma ruta. Las carpetas que empiezan por punto, como .git/ y .htmlpress/, y node_modules/, se omiten. Cada una de las páginas siguientes cubre un área de la redacción.

Funcionalidades

Frontmatter

Las etiquetas de <head> que definen el título, la descripción y el orden de una página.

Encabezados

ID generados, anclas personalizadas y la tabla de contenidos.

Enlaces

Enlaces internos, externos y de ancla, URL y la ruta base.

Multimedia

Imágenes con zoom, vídeo y audio incrustados.

Formato de texto

Negrita, cursiva, listas, citas, notas al pie, listas de definiciones y abreviaturas.

Elementos enriquecidos

Tablas, avisos, pestañas, pasos, tarjetas, insignias, botones y árboles de archivos.

Bloques de código

Botones de copiar, pestañas de código, pestañas de gestores de paquetes y terminales.

Sintaxis avanzada

Etiquetas de head, scripts, diagramas Mermaid y componentes del proyecto.
