Authoring

Htmlpress accepts plain semantic HTML out of the box, plus a small set of htmlpress-* components for what HTML has no element for: callouts, tabs, steps, cards, terminals, diagrams and more. A project is a folder: every .html file in it is a page, and every other file is copied to the output as-is, at the same path. Dot-folders such as .git/ and .htmlpress/, and node_modules/, are skipped. Each page below covers one area of the authoring surface.

Features

Frontmatter

The <head> tags that set a page's title, description and order.

Headings

Generated IDs, custom anchors and the table of contents.

Links

Internal, external and anchor links, URLs and the base path.

Media

Images with zoom, video and audio embeds.

Text Formatting

Bold, italic, lists, blockquotes, footnotes, definition lists and abbreviations.

Rich Elements

Tables, callouts, tabs, steps, cards, badges, buttons and file trees.

Code Blocks

Copy buttons, code tabs, package manager tabs and terminals.

Advanced Syntax

Head tags, scripts, Mermaid diagrams and project components.
