Authoring

Htmlpress accepts plain semantic HTML out of the box, plus a small set of htmlpress-* components for what HTML has no element for: callouts, tabs, steps, cards, terminals, diagrams and more. A project is a folder: every .html and .md file in it is a page, and every other file is copied to the output as-is, at the same path. Dot-folders such as .git/ and .htmlpress/, and node_modules/, are skipped. Each page below covers one area of the authoring surface.

Every example shows its HTML and its Markdown, the Livemark syntax a .md page takes: pick one tab and every example on every page follows it.

Features

Any element, style or script, and what htmlpress changes in it.

The <head> tags that set a page's title, description and order.

Generated IDs, custom anchors and the table of contents.

Internal, external and anchor links, URLs and the base path.

Images with zoom, video and audio embeds.

Bold, italic, lists, blockquotes, footnotes, definition lists and abbreviations.

Tables, callouts, tabs, steps, cards, badges, buttons and file trees.

Copy buttons, code tabs, package manager tabs and terminals.

Head tags, scripts, Mermaid diagrams and project components.

Pages written in Markdown, with frontmatter and directives.
