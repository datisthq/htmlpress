Links

A page is written to the same path it was read from, so links between pages keep working. index.html is served at its folder: guides/index.html at /guides/.

Internal Links

Link to other pages in your documentation, root-relative or relative to the page:

<a href="/introduction.html">Introduction</a>
<a href="headings.html">Headings</a>

Renders as: Introduction

With base set in htmlpress.yaml, every root-relative URL in the build (in href, src, srcset, poster and action, in pages, the layout and the config's HTML alike) gets it as a prefix: write /guide.html and the site links to /repo/guide.html. Relative and absolute URLs are left alone, and so are url()s in a page's own CSS. start and preview serve the site under the base too, and send / there.

The navigation groups pages by their top folder, named by the folder's index.html title, else the folder's name. Pages at the root come ungrouped.

External Links

Link to external resources:

<a href="https://github.com">GitHub</a>

Renders as: GitHub

Anchor Links

Link to a specific heading on the current page by its id:

<a href="#internal-links">See Internal Links</a>

Renders as: See Internal Links

A heading on another page is its URL plus the id: Custom Heading IDs. See Headings for how ids are made.

Auto Links

A bare URL in text stays text in HTML; turning it into a link automatically at build time is planned. Until then, wrap it in an <a>.
