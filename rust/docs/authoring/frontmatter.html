Frontmatter

A page has no YAML frontmatter: its metadata is the HTML <head> itself. A page is a full document or a fragment, and htmlpress reads both the same way. Every tag is optional; htmlpress derives sensible defaults from the file when one is missing. 

<title>Getting started</title>
<meta name="description" content="Install and run it.">
<meta name="order" content="1">

<h1>Getting started</h1>
<p>Plain HTML, styled by the theme.</p>

The body becomes the page's content inside the layout. Give every page one <title> and one <h1>.

Article metadata

Identity and presentation of the page.

Tag Default Purpose
<title> first <h1>, else the file name Names the page in the navigation and the browser tab.
<meta name="description"> description from htmlpress.yaml The page's description for search engines and social previews.
<meta name="image"> none The image shown when the page is shared, as og:image; a root-relative URL is made absolute with site.
anything else in <head> none Kept: a page's own <link>, <style> or <script> is added to the layout's head, after the theme.

A short navigation label, an icon, authors, a date and tags for a page will come as further <meta> tags.

Sidebar settings

How the page shows up in the navigation.

Tag Default Purpose
<meta name="order"> none (sorted by path) An integer sort position; see "Ordering rules" below.
<meta name="layout"> the site's layout Wraps the page in .htmlpress/layouts/<name>.html instead, for a page that wants different chrome, such as a landing page without the sidebar. A missing layout fails the build; see Overriding and Escaping.

Hiding a page from the navigation while keeping it reachable, and turning off a page's table of contents, will come as <meta> tags.

Ordering rules

  • The root index.html always leads.
  • Pages with an order come next, ascending; a negative order sorts before a positive one.
  • Pages without one follow, by path.

An order that is not an integer fails the build. A 404.html at the root is the page a host shows for a missing URL; it is left out of the navigation, and a project without one gets a built-in "Page not found".

URL

A page is written to the same path it was read from, and index.html is served at its folder: guides/index.html at /guides/. See Links.
