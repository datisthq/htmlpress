Code Blocks

A code block is a <pre><code>, styled by the theme in its mono font. Every code block gets a copy button. Escape the code inside it: &lt; for < and &amp; for &. Tabs of code blocks are covered under Code Tabs. 

<pre><code>const greeting = "&lt;hello&gt;"</code></pre>

Renders as:

const greeting = "<hello>"

Syntax Highlighting

A language-* class on the <code> colors the block at build time with VS Code's TextMate grammars, the same output as Shiki, in a light and a dark theme that follow the reader's (see Syntax Themes). Over 220 languages are built in, with their usual aliases (ts, sh, yml); an unknown one, or a block holding markup of its own, stays plain. 

<pre><code class="language-rust">fn main() {
    println!("hello");
}</code></pre>

Renders as:

fn main() {
    println!("hello");
}

Titles

A <figure> with a <figcaption> names a block in plain HTML: 

<figure>
  <pre><code>title: Htmlpress</code></pre>
  <figcaption>htmlpress.yaml</figcaption>
</figure>

Renders as:

A title bar on the code block itself, holding the file name.

Line Highlighting

data-lines on a highlighted block marks lines, counted from 1: single lines and ranges, comma-separated. 

<pre><code class="language-js" data-lines="2">…</code></pre>
const a = 1
const b = 2
const c = 3

Word Highlighting

Highlighting every occurrence of a word in a code block.

Line Numbers

data-line-numbers on a highlighted block numbers its lines; data-line-numbers="10" starts from 10. The copy button leaves the numbers out. 

const a = 1
const b = 2

Diff Lines

Marking lines of a code block as added or removed. Inside a terminal, <ins> and <del> already color output green and red.

Focus Lines

Dimming every line of a code block but the focused ones.

Error and Warning

Marking lines of a code block as errors or warnings.

Collapsible Code

A <details> around a long block hides it behind its <summary>: 

<details>
  <summary>The full config</summary>
  <pre><code>…</code></pre>
</details>

Limiting a code block to its first lines, with a button that reveals the rest.

Language Icons

A language icon in a titled code block's title bar.

TypeScript Support

Inline type information on hover in TypeScript code blocks.

NPM Commands

Write one npm or npx command inside <htmlpress-package-tabs> and the build turns it into tabs for npm, pnpm, yarn and bun, synced across the site. Other lines stay as written. 

<htmlpress-package-tabs>
  <pre><code>npm install --save-dev gethtmlpress</code></pre>
</htmlpress-package-tabs>

Renders as:

npm install --save-dev gethtmlpress

Terminal

A <pre> inside <htmlpress-terminal> looks like a terminal window, dark in both themes and named by title. Inside it, <kbd> is a typed command (the prompt is added), <samp> plain output, and <ins>, <del> and <mark> green, red and yellow output. 

<htmlpress-terminal title="zsh">
  <pre><kbd>htmlpress build docs</kbd>
<samp>built 7 pages…</samp>
<ins>✓ ready</ins></pre>
</htmlpress-terminal>

Renders as:

htmlpress build docs
built 7 pages and 0 files into docs/.htmlpress/build
✓ ready
✗ 1 page failed
! 1 warning
