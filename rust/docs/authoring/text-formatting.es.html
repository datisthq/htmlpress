Formato de texto

El texto es HTML simple, y el tema da estilo a los propios elementos: escribe marcado semántico y ya tendrá buen aspecto. Sin clases, sin estilos en línea.

Negrita y cursiva

<strong>bold text</strong> and <em>italic text</em> and <strong><em>bold italic</em></strong>

Se renderiza como: texto en negrita y texto en cursiva y negrita y cursiva

Tachado

<s>deleted text</s>

Se renderiza como: texto eliminado

Código en línea

Use <code>const x = 1</code> for inline code.

Se renderiza como: Usa const x = 1 para código en línea.

<kbd> marca una tecla: pulsa Ctrl + C para copiar.

Resaltado de código en línea

Un <code> en línea con una clase language-* se resalta como un bloque, en los mismos temas claro y oscuro. 

Run <code class="language-js">await build("docs")</code> first.

Se renderiza como: Ejecuta primero await build("docs").

Notas al pie

No hace falta ningún componente. Una referencia a una nota al pie es un enlace <sup> a un <li> con ese id; al pasar el ratón o enfocar la referencia se muestra una vista previa de su nota, sin los enlaces de vuelta. Sin el script, el enlace sigue saltando a la nota. 

Here is a sentence with a footnote<sup><a href="#note-1" id="ref-1">1</a></sup>.

<ol>
  <li id="note-1">This is a numbered footnote. <a href="#ref-1">↩</a></li>
</ol>

Se renderiza como:

Aquí hay una frase con una nota al pie1 y otra2.

  1. Esto es una nota al pie numerada. ↩
  2. Pasa el ratón por la referencia para leer la nota en su sitio. ↩

Listas de definiciones

Define términos con sus descripciones:

<dl>
  <dt>Page</dt>
  <dd>An .html file in a project</dd>
  <dt>Escape</dt>
  <dd>A project file that replaces a built-in asset</dd>
  <dd>Kept under .htmlpress/</dd>
</dl>

Se renderiza como:

Página
Un archivo .html de un proyecto
Escape
Un archivo del proyecto que sustituye a un recurso integrado
Se guarda en .htmlpress/

Abreviaturas

No hace falta ningún componente. Un <abbr title> muestra su forma completa al pasar el ratón o al enfocarlo; sin el script, el título sigue siendo un tooltip nativo. 

The <abbr title="HyperText Markup Language">HTML</abbr> standard is maintained by <abbr title="World Wide Web Consortium">W3C</abbr>.

Se renderiza como: El estándar HTML lo mantiene el W3C.

Emoji

Escribe los caracteres emoji directamente; las páginas están en UTF-8:

🚀 Launch 🎉 Celebrate ❤️ Love ⚠️ Careful ✅ Done

Se renderiza como: 🚀 Lanzar 🎉 Celebrar ❤️ Amor ⚠️ Cuidado ✅ Hecho

Los códigos cortos de GitHub se convierten en emoji al compilar; uno desconocido, y cualquier cosa dentro de código o de un elemento data-literal, se queda tal como está escrito: 

Ship it :rocket: :tada:

Se renderiza como: Publícalo :rocket: :tada:
