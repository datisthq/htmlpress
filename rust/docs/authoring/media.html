Media

Images are plain <img> elements, scaled to the content width. Wrap one in <figure> with a <figcaption> for a caption.

Internal Images

Reference images from your project; every file that is not a page is copied to the output at the same path: 

<img src="/screenshots/docs.webp" alt="An htmlpress docs page">

External Images

Reference images from external URLs:

<img src="https://picsum.photos/seed/htmlpress/800/300" alt="Placeholder">

Base64 Images

Embed small images directly using data URIs:

<img src="data:image/png;base64,iVBORw0KGgo…" alt="banner">

Themed Images

An image shown only in the light or only in the dark theme. A <picture> with a prefers-color-scheme source follows the system setting today, but not the header's theme toggle.

Image Zooming

An image inside <htmlpress-zoom> opens full screen on click; a click anywhere closes it. It works with internal, external and base64 images alike. 

<htmlpress-zoom><img src="screenshot.png" alt="The docs site"></htmlpress-zoom>

Video Blocks

A link inside <htmlpress-youtube> becomes the video's player (a watch, youtu.be, embed, shorts or live URL); without the script it stays a link: 

<htmlpress-youtube>
  <a href="https://www.youtube.com/watch?v=dQw4w9WgXcQ">The video</a>
</htmlpress-youtube>

Renders as:

The video

Audio Blocks

A link inside <htmlpress-soundcloud> becomes the track's player; without the script it stays a link: 

<htmlpress-soundcloud>
  <a href="https://soundcloud.com/flume/never-be-like-you-feat-kai">The track</a>
</htmlpress-soundcloud>

The track
