Text Formatting

Text is plain HTML, and the theme styles the elements themselves: write semantic markup and it already looks right. No classes, no inline styles.

Bold and Italic

<strong>bold text</strong> and <em>italic text</em> and <strong><em>bold italic</em></strong>

Renders as: bold text and italic text and bold italic

Strikethrough

<s>deleted text</s>

Renders as: deleted text

Inline Code

Use <code>const x = 1</code> for inline code.

Renders as: Use const x = 1 for inline code.

<kbd> marks a key: press Ctrl + C to copy.

Inline Code Highlighting

Language-aware syntax highlighting for inline code and code blocks.

Blockquotes

<blockquote><p>This is a blockquote.</p></blockquote>

Renders as:

This is a blockquote.

Task Lists

A list item led by a disabled checkbox:

<ul>
  <li><input type="checkbox" checked disabled> Completed task</li>
  <li><input type="checkbox" disabled> Pending task</li>
</ul>

Renders as:

  • Completed task
  • Pending task

Footnotes

No component needed. A footnote reference is a <sup> link to an <li> with that id; hovering or focusing the reference previews its note, without the links back. Without the script, the link still jumps to the note. 

Here is a sentence with a footnote<sup><a href="#note-1" id="ref-1">1</a></sup>.

<ol>
  <li id="note-1">This is a numbered footnote. <a href="#ref-1">↩</a></li>
</ol>

Renders as:

Here is a sentence with a footnote1 and another2.

  1. This is a numbered footnote. ↩
  2. Hover the reference to read the note in place. ↩

Definition Lists

Define terms with their descriptions:

<dl>
  <dt>Page</dt>
  <dd>An .html file in a project</dd>
  <dt>Escape</dt>
  <dd>A project file that replaces a built-in asset</dd>
  <dd>Kept under .htmlpress/</dd>
</dl>

Renders as:

Page
An .html file in a project
Escape
A project file that replaces a built-in asset
Kept under .htmlpress/

Abbreviations

No component needed. An <abbr title> shows its full form on hover or focus; without the script, the title stays a native tooltip. 

The <abbr title="HyperText Markup Language">HTML</abbr> standard is maintained by <abbr title="World Wide Web Consortium">W3C</abbr>.

Renders as: The HTML standard is maintained by W3C.

Emoji

Write emoji characters directly; pages are UTF-8:

🚀 Launch 🎉 Celebrate ❤️ Love ⚠️ Careful ✅ Done

Renders as: 🚀 Launch 🎉 Celebrate ❤️ Love ⚠️ Careful ✅ Done

GitHub-style shortcodes such as :rocket:, turned into emoji at build time.
