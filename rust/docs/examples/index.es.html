Ejemplos

Una página en htmlpress es un documento HTML completo, así que puede ser cualquier cosa que un navegador sepa mostrar: un panel, un informe imprimible, una presentación de diapositivas, un explorador interactivo. Cada ejemplo de abajo es un único archivo .html autónomo con su propio <style> y <script>, escrito como lo escribe un agente de programación, en torno a datos públicos reales. Se integra en el layout del sitio, sigue su tema claro y oscuro, y no necesita paso de compilación, framework ni biblioteca de gráficos.

Cada cifra proviene de un conjunto de datos público, citado al pie de su página. Abre el código fuente con el enlace Editar en GitHub: todo lo que una página necesita está en ese único archivo.
