太阳能电池板：便宜了 500 倍

一个只有一个 HTML 页面的交互式浏览器。在对数和线性坐标之间切换图表，拖动两个滑块选择任意年份区间，核心数字、其下方的句子以及折线的高亮区段都会重新计算。没有任何预先计算：页面只携带五十个价格，随着你的操作实时计算。

为什么用对数坐标

在线性坐标轴上，故事在 1985 年就结束了：价格已从 $132 跌到 $17，此后的一切都是贴着底部的一条平线。在对数坐标轴上，网格的每一格代表十倍的变化，所以稳定的百分比下降就是一条直线——而太阳能的这条线五十年来几乎是直的。这种稳定的速率就是所谓的斯旺森定律（Swanson's law）：全球累计出货量每翻一番，组件价格往往下降约五分之一。

实现方式

  • 一个状态，一次渲染。坐标类型和两个年份保存在一个小对象里；每个控件都写入它，并调用同一个函数来重绘图表、改写数字，因此不会出现不同步。
  • 控件都是原生的：两个用 accent-color 着色的 <input type="range">，以及一对按钮，其 aria-pressed 同时作为选中按钮的样式钩子。
  • 句子是生成的：减半时间为 ln 2 / −ln(1 + rate)，并用文字写出来，因此从不看坐标轴的读者也能得到答案。
