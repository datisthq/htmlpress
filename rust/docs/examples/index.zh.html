示例

htmlpress 中的页面是一个完整的 HTML 文档，因此浏览器能显示的任何东西它都可以是：仪表盘、可打印的报告、幻灯片、交互式探索器。下面每个示例都是一个自包含的 .html 文件，带有自己的 <style> 和 <script>，按编程智能体的写法围绕真实公开数据编写。它嵌入站点的布局，跟随站点的浅色和深色主题，无需构建步骤、框架或图表库。

每个数字都来自公开数据集，并在所在页面底部注明出处。通过“在 GitHub 上编辑”链接打开源码：页面所需的一切都在这一个文件里。
