World population: the climb to ten billion

An infographic poster in one HTML page: three hero numbers, an interactive stacked area chart, a bar timeline and a sparkline of twelve thousand years. Every chart is inline SVG drawn by a few lines of script from the numbers in the page, and every color is a token that switches with the site's dark mode.

How it's built

  • Hero numbers are a CSS grid whose 1px gap shows the border color through, so the tiles get hairline dividers without a single border rule.
  • The stacked area is computed in the browser: each region's band is a path from its baseline to its top, and an invisible overlay snaps the crosshair to the nearest five-year step. A ResizeObserver redraws it at the real width, so the labels stay 11px on a phone.
  • The billion timeline is no chart library at all: each bar is a ::before whose width is a --years custom property, and the projected rows switch to a hatched fill.

Source: UN World Population Prospects 2024, with the long-run series from HYDE and Gapminder, as compiled by Our World in Data.
