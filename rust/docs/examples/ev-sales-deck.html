Electric car sales deck

A five-slide briefing that lives inside a docs page. Each slide is a 16:9 box whose type is sized in container units, so the whole slide scales as one, the way a presentation does, from a phone to a projector. Swipe or scroll between slides, use the buttons or the arrow keys once the deck has focus, or press F for full screen. A link to #evd-3 opens on the third slide.

How it's built

  • Slides are <section>s in a flex row with scroll-snap-type: x mandatory; each is a size container, and every font size is in cqw, so a slide keeps its proportions at any width.
  • Charts are SVG with a fixed viewBox, drawn once from the data and scaled with the slide, so a chart and its type always grow together.
  • Navigation is about thirty lines: the buttons and arrow keys scroll the track, and an IntersectionObserver keeps the counter and the dots in step with swipes. requestFullscreen() turns the stage into a projector view.

Source: IEA Global EV Outlook, as compiled by Our World in Data (updated June 2026). The 2025 values are the latest year reported and the most likely to be revised.
