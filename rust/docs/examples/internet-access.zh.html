      实现方式

      • 象形图由十个空的 <i> 元素组成。每个元素用双色标的 linear-gradient 上色，再用 CSS mask 裁成人形，因此一个人形可以只填充一部分：15.6% 那一行填满一个半人形，完全不用绘制 SVG。
      • 每张华夫图都是十乘十的 CSS 方格网格，从最下面一行往上，用同一色相的两种深浅填充：2005 年已上网的人，以及此后新上网的人。单一的顺序色相让它始终是同一个指标在两个时间点的呈现。
      • 打印：一个 @media print 块设置 print-color-adjust: exact，让方格保留颜色，去掉简报的边框，并避免任何图表被拆到两页。

      来源： 国际电信联盟（ITU），Facts and Figures，经 世界银行，由 Our World in Data 整理。
