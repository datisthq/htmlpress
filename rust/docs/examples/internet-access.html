Internet access: a one-page fact sheet

A fact sheet meant to be printed as well as read: big-number facts, a pictogram comparing 2005 with 2025 and a waffle chart for every region and income group, each square one percent of its people. It sits on one sheet in the browser's print preview, and a @media print block drops the page chrome and keeps the colors.

      How it's built

      • The pictogram is ten empty <i> elements. Each is painted with a two-stop linear-gradient and cut to a person's shape with a CSS mask, so a figure can be partly filled: the 15.6% row fills one and a half figures, with no SVG drawing at all.
      • Each waffle is a ten-by-ten CSS grid of squares, filled from the bottom row up in two shades of one hue: those online in 2005, and those who came online since. One sequential hue keeps it a single measure seen at two dates.
      • Print: a @media print block sets print-color-adjust: exact so the squares keep their color, removes the sheet's frame and keeps every chart from splitting across pages.
